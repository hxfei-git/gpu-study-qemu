# GPGPU 实验进度

| 缩写 | 英文全称 | 中文含义 |
| --- | --- | --- |
| GPGPU / GPU | General-Purpose Computing on Graphics Processing Units / Graphics Processing Unit | GPU 通用计算／图形处理器 |
| QEMU | Quick Emulator | 仿真与虚拟化工具 |
| CP | Command Processor | 命令处理器 |
| GPUVM | GPU Virtual Memory | GPU 虚拟内存 |

## 1. 当前阶段

当前主线是 QEMU GPGPU 实验开发，处于第三阶段完成后的整理与后续范围确认。统一访存和协议版本 3 的软件栈已通过本地全栈验证，GPUVM 开、关两种模式都能运行既有计算示例，结果见[软件栈第 5 节](<../software/gpgpu/README.md#build-and-validation>)。

这里只记录实现与运行验证的状态。用户对对象关系的掌握情况按反馈另行记录；异常恢复等后续能力尚未实现。

## 2. 近期任务与下一步

第四阶段尚未开始实现。现有开发环境可以运行全栈验证；剩余的环境事项是验证从零引导开发环境，所需材料和本机缺少的部分见[软件栈第 5.1 节](<../software/gpgpu/README.md#offline-materials>)。

下一步从实际异常中选择第四阶段的近期范围，先起草停止条件、资源保留与恢复后继续计算的流程，再由用户审定。不在此时预先固定全部复位接口、故障矩阵或工期。
