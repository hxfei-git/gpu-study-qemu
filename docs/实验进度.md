# GPGPU 实验进度

| 缩写 | 英文全称 | 中文含义 |
| --- | --- | --- |
| GPGPU / GPU | General-Purpose Computing on Graphics Processing Units / Graphics Processing Unit | GPU 通用计算／图形处理器 |
| QEMU | Quick Emulator | 仿真与虚拟化工具 |
| dcache | Data Cache | 数据缓存；本实验指翻译后的设备级数据缓存 |
| GPUVM | GPU Virtual Memory | GPU 虚拟内存 |

## 1. 当前阶段

Qwen2.5-0.5B-Instruct 与原版 YOLO11n 的真实算子评估已完成本机数值与性能核对，包含同客体双进程竞争；独立代码评审发现的问题已修复，受影响入口已复验。现行组件升级见 [PROTOCOL_V7.md](<../software/gpgpu/PROTOCOL_V7.md>)；实际结果、估算假设、集成建议、未覆盖范围和日志只在[软件栈第 5 节](<../software/gpgpu/README.md#model-eval-results>)维护。完整模型集成尚未开始。

这里只记录实现与运行验证的状态。用户对对象关系的掌握情况按反馈另行记录；运行中的强制中止与复位恢复尚未实现。

## 2. 近期任务与下一步

本轮算子适配与分阶段评估已收尾。后续若推进完整模型工作，先依据[软件栈的集成建议](<../software/gpgpu/README.md#model-eval-results>)确定范围，不以独立算子比较通过代替网络推理与质量验证。

运行中强制停止和复位恢复仍属于独立的第四阶段，尚未开始实现；本轮不以清除软件状态代替停止确认。已确认的边界和暂缓条件继续在[实验大纲](<./QEMU GPGPU 实验大纲.md>)维护。

现有开发环境可以运行全栈验证；从零引导开发环境仍未验证，所需材料和本机缺少的部分见[软件栈第 5.1 节](<../software/gpgpu/README.md#offline-materials>)。
