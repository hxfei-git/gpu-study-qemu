| GPGPU / GPU | General-Purpose Computing on Graphics Processing Units / Graphics Processing Unit | GPU 通用计算／图形处理器 |

## 1. 当前阶段

当前主线是 QEMU GPGPU 实验开发，处于第三阶段完成后的剩余规格确认。现行接口见 [PROTOCOL_V5.md](<../software/gpgpu/PROTOCOL_V5.md>)；失败收尾修复已完成并通过全栈与定向核对，实际结果、日志与未覆盖范围只在[软件栈第 5 节](<../software/gpgpu/README.md#build-and-validation>)维护。

这里只记录实现与运行验证的状态。用户对对象关系的掌握情况按反馈另行记录；运行中的强制中止与复位恢复尚未实现。

## 2. 近期任务与下一步

先从[第三阶段规格评审的待确认入口](<./第三阶段规格评审.md#review-index>)确定剩余改进的取舍，再选择第四阶段的近期范围。已确认的边界和暂缓条件在[实验大纲](<./QEMU GPGPU 实验大纲.md>)维护，不重新列为待确认事项。

第四阶段尚未开始实现。范围确定后，再起草停止条件、资源保留与恢复后继续计算的流程，由用户审定；不预先固定全部复位接口、故障矩阵或工期。

现有开发环境可以运行全栈验证；从零引导开发环境仍未验证，所需材料和本机缺少的部分见[软件栈第 5.1 节](<../software/gpgpu/README.md#offline-materials>)。
